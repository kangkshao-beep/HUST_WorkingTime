# Working Hour

A simple timesheet app for contract/gig workers who need to submit a working hour report.

Features:
- Clock in/out easily with support for multiple break times
- Excel/CSV export
- Automatic iCloud sync

## Mac release

Download the Mac app from [GitHub Releases](https://github.com/kangkshao-beep/HUST_WorkingTime/releases). Requires macOS 14 or later; the Universal Binary supports Apple silicon and Intel.

From V0.2, use the **语言 / 語言 / Language** menu at the top right of the window, or open Settings with **⌘,**, to select **跟随系统**, **简体中文**, **繁體中文（香港）**, or **English**. Changes apply immediately and persist across launches.

The downloadable Mac build stores attendance locally. CloudKit sync and App Group widget sharing require separate signing/capability setup. See [更新说明](CHANGELOG.md) for version details and upgrade instructions.
